# Contributing to Media Cover Gallery

Thanks for wanting to help. Bug reports, suggestions and code contributions are all welcome.

## Ways to contribute

- **Bugs and ideas:** open an issue on this repository, or email [contact@kgniewek.com](mailto:contact@kgniewek.com).
- **Code:** open a pull request against this repository.

## Pull request guidelines

- Keep each pull request focused on one change.
- Describe what the change does and why.
- Make sure `npm run build` passes before you submit.
- Don't commit `main.js`, `data.json` or any API keys.
